# 历史版本

仓库保留了 v0.1 到 v0.4 的可下载包。每个压缩包对应当时真实保存的版本内容，便于回溯和下载。

- [`NeonEmber-v0.1-Web.zip`](NeonEmber-v0.1-Web.zip)：最初的浏览器 HTML 原型；解压后打开 `rogue-neon.html`。
- [`NeonEmber-v0.2-Windows-x64.zip`](NeonEmber-v0.2-Windows-x64.zip)：Windows x64 免安装客户端。
- [`NeonEmber-v0.3-Windows-x64.zip`](NeonEmber-v0.3-Windows-x64.zip)：从 v0.3 独立验收目录重新打包的 Windows x64 免安装客户端。
- [`NeonEmber-v0.4-Windows-x64.zip`](NeonEmber-v0.4-Windows-x64.zip)：当前 Windows x64 免安装客户端。

验证记录：

- [`NeonEmber-v0.3-validation.md`](NeonEmber-v0.3-validation.md)
- [`NeonEmber-v0.4-validation.md`](NeonEmber-v0.4-validation.md)

v0.1 是网页原型；v0.2 起改为 Windows 原生客户端。当前主分支和 `v0.4` Release 对应最新版本。
