# v0.4 战术 AI 验证与固定路线对照

验证日期：2026-10-12。验证对象是实际 C# 战斗核心；不是另一套模拟模型。原有 26 项核心回归、23 项战术/体系回归、新增 10 项行为测试均通过，共 59 项。另运行同一测试源码、同种子与同构筑的 21 组 v0.3 / v0.4 路线诊断。

## 行为测试的实际后果

| 场景 | 不处理机制 | 使用反制 | 验证内容 |
| --- | --- | --- | --- |
| 持续圆周轨迹被投弹怪观察后锁定 | 剩余 75 HP | 预告后反向：100 HP | 从已发生位移识别曲线；锁定点没有追踪反向移动 |
| 中继组织压制 | 忽略节点：75 HP | 真实弹丸击破节点：100 HP | 压制先于截击；断链取消蓄力、危险区并让队员失序 |
| 棱镜卫受到相同 100 基础伤害 | 正面 35 伤害 | 侧面 110、背面 145、干扰后 100 | 方向装甲有真实伤害差异，朝向不能瞬间转身 |
| 棱镜卫正在蓄力 | 正面开火仍完成攻击 | 绕到背面命中后取消攻击并暴露 | 不是只能等它出招；侧背有可主动制造的窗口 |
| 维护者为 100 HP 的受伤盟友修复 | 修复后约 135.1 HP | 引导中直接命中：维持 100 HP | 修复确实改变生命值；打断确实取消治疗 |
| Boss 核心受到相同 100 基础伤害 | 通常状态 100 伤害 | 出招后的恢复期 135 伤害 | Boss 三类出招、半血阶段与反击窗口都进入实际状态 |

环形攻击的中央与外部、有限长度线形攻击的侧方通过真实碰撞验证为安全区。新增回归还覆盖：玩家原地不动时，Boss 第三招环震仍能启动；暂停不会推进已学习的轨迹、编队阶段或维修引导；重开清除轨迹记忆。

## v0.3 与 v0.4 对照方法

先冻结 v0.3 的 `Game.cs`、`Tactics.cs`、`World.cs`，随后分别把同一 `AdaptiveTests.cs` 编译到旧、新核心。种子为 511、512、513；每组最多 300 秒、初始 100 HP。不购买、不领取医疗、不增加生命/减伤/护盾等级，不在测试中恢复生命或设为不死；Boss 本身的正常击杀回血保留。累计受伤逐帧记录，所以即使 Boss 回血，之前的伤害也不会被抹掉。

固定构筑从第 0 秒开始生效，关闭经验升级，仅用于控制武器变量、检验怪物能否应对成熟火力，不代表正常游戏的成长时间线。

- 早期构筑：裂隙针 2。
- 武器成型：裂隙针 5、链式信标 4、轨道棱 4、超载核心 4、高频谐振 3。
- 体系成型：以上武器加热写烙印 3、破绽焚解 2、传火证词 1（余烬 6 点觉醒），以及离线替身 1、静默频段 1（回声 2 点与跨系联动）。实际 ID 为 `ember_brand3 / ember_breach2 / ember_cascade1 / echo_decoy1 / echo_jammer1`。

圆周策略只沿 185 像素半径持续转圈。反应策略在附近出现预告后反向并尝试冲刺，设有 1.5 秒决策间隔；它只读取当前可见状态，没有未来碰撞信息。第三种策略还始终锁定武器范围内最近的节点。后两种都只是简单、可复现的控制器，不等于熟练玩家。

## 最终路线结果

同一行内三个数字依次对应种子 511 / 512 / 513；300 秒表示到测试截止仍存活。

| 构筑与策略 | v0.3 存活秒数 | v0.4 存活秒数 | v0.4 截止时 HP |
| --- | --- | --- | --- |
| 武器成型，持续圆周 | 300 / 300 / 300 | 201.76 / 205.78 / 187.10 | 0 / 0 / 0 |
| 武器成型，观察预告后反向冲刺 | 300 / 300 / 300 | 300 / 283.92 / 300 | 1.77 / 0 / 45.60 |
| 体系成型，持续圆周 | 300 / 300 / 300 | 187.90 / 187.43 / 181.47 | 0 / 0 / 0 |
| 体系成型，观察预告后反向冲刺 | 300 / 300 / 300 | 300 / 300 / 300 | 100 / 66.74 / 16.45 |
| 体系成型，反向冲刺并始终锁最近节点 | 300 / 300 / 300 | 300 / 300 / 300 | 46.08 / 49.36 / 66.26 |

这批样本说明持续圆周不再足以避开所有威胁，看到预告后改变路线和使用回声能力能改变结果。它不证明所有玩家都应采用同一种走法。自动锁远处节点在两个种子中比不锁更差、一个种子更好，体现了火力分配与眼前威胁的取舍；“只要有节点就永远优先”不是保证最优的策略。

早期固定裂隙针 2 的圆周路线从旧版 57.88 / 65.83 / 74.45 秒变为 55.68 / 58.57 / 50.33 秒。这组完全没有正常升级，不能代表真实新手曲线；不过它明确显示早期压力也有所增加，后续试玩应观察这一点。

## 成型火力下是否真正出招

统计使用 `Enemy.AttackSerial`：只在完成攻击或实际修复脉冲后递增，开始预告、预告被击破均不计为完成。这里分别报告攻击精英和支援精英，避免把未找到伤员与来不及开火混为同一问题。

| v0.4 体系成型策略 | 棱镜卫已完成至少一次攻击 / 出场数 | 维护者已完成修复 / 出场数 |
| --- | --- | --- |
| 持续圆周 | 1/8、1/8、2/7 | 0/7、0/7、0/6 |
| 看预告反向冲刺 | 5/17、7/17、6/17 | 0/16、0/16、0/16 |
| 反向冲刺并锁节点 | 5/17、5/17、6/17 | 0/16、0/16、0/16 |

棱镜卫会在成型伤害下真正出手，但也允许被主动打断、拆队与击杀；没有强制无敌或锁血保底。维护者在这套持续燃烧和连锁火力构筑下没有完成修复，因为燃烧会禁止新引导、直接命中会取消引导，盟友也可能先被杀死；这是该构筑对支援单位的实际压制结果，不能声称“所有精英都稳定出招”。独立维修正反测试验证了没有持续压制时它会治疗，而打断后不会治疗。

## 回归、容量和边界

原有回归断言没有被删除。只有两处按明确的新设计调整：旧“连入节点后立刻开火”的夹具改成等待压制阶段；旧单一圆区半径限制扩展成圆半径 ≤96、环外半径 ≤180 且安全内圈 ≥100、线半宽 ≤28 且长度 ≤460，并使用实际形状碰撞检查剩余空间。

仍验证 360 敌人、900 弹丸、280 经验球、220 特效、12 危险区与 3 个同时特殊攻击的容量限制；长局检查新增轨迹估计、维修计时、朝向、线端点与环内圈都保持有限数值。高生命值的 900 秒模拟只用于稳定性与容量回归，未用于上面的难度结论。

本版 AI 是有状态的观察、规则与编队决策，不是学习模型。安全区域检查是有限候选路径检查，不能保证任意拥挤、子弹组合下都有无伤解。这里只验证战斗核心；原生画面清晰度、真人反应负担、完整成长过程与长期流派平衡仍需要客户端试玩。
